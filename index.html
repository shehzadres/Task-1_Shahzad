The web is a dynamic, inclusive information system.

I studied full-stack development the way it's meant to be learned: fundamentals first. Semantic HTML for structure, CSS Grid and Flexbox for layout, vanilla JavaScript for behavior — before ever reaching for a framework. That order stuck, and it still shows in the way I build.

Every project starts in grayscale. If the hierarchy doesn't hold without color, color won't save it. Then comes a warm, grounded palette, fluid type with clamp(), and an accessibility pass that isn't an afterthought.

How a project moves

Six stages, from discovery to audit.

  1. 1

    Discovery

    Define the brief and the "how might we."

  2. 2

    Wireframe

    Grayscale, mobile-first, hierarchy over decoration.

  3. 3

    Semantics

    HTML landmarks before a single line of CSS.

  4. 4

    Style

    Grid and Flexbox, a two-font palette, real content.

  5. 5

    Logic

    State and interactivity, built to be predictable.

  6. 6

    Audit

    Performance, contrast, and keyboard access, checked.
